# PowerChain Protocol Packages

Canonical protocol contracts for PowerChain `1.0.0`.

```text
powerchain-protocol/
├── miner/   Proof-of-Energy, DePIN, Solana, Helium and community-energy contracts
└── cct/     verified carbon-credit issuance and retirement contracts
```

These packages define deterministic cross-application contracts. They do not own database
persistence, UI state or private keys.

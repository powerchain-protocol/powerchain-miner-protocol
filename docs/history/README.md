# Documentation History

The public product version remains **PowerChain `1.0.0`**.

This directory contains implementation history that is useful for maintainers but should not
compete with current operational documentation.

```text
history/
├── migrations/           internal schema/protocol evolution notes
└── working-iterations/   superseded working release labels
```

Working iteration labels such as `v1.1`, `v1.2`, and `v1.3` were never separate supported
public product releases. Their completed functionality was folded into canonical `1.0.0`.

Current documentation starts at [`../README.md`](../README.md).
